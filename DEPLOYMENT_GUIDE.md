## 🚀 СПОСОБ 1: Загрузка через GitHub (без командной строки)

### Шаг 1. Создание аккаунта на GitHub

1. Перейдите на сайт [github.com](https://github.com)
2. Нажмите **Sign up**
3. Введите email, придумайте пароль и username
4. Подтвердите email (придёт письмо)

### Шаг 2. Создание репозитория

1. После входа нажмите кнопку **+** в правом верхнем углу → **New repository**
2. Заполните поля:
   - **Repository name**: `alfa-credit-cabinet` (или любое другое)
   - **Description**: `Умный кредитный кабинет предпринимателя — Альфа-Банк`
   - **Public** или **Private** (для хакатона лучше Private)
   - ✅ Поставьте галочку **Add a README file**
   - ✅ Поставьте галочку **Add .gitignore** → выберите **Node**
3. Нажмите **Create repository**

### Шаг 3. Загрузка файлов проекта

**Вариант А: Через веб-интерфейс (для небольших проектов)**

1. В созданном репозитории нажмите **Add file** → **Upload files**
2. Перетащите все файлы проекта в окно загрузки
3. **ВАЖНО**: НЕ загружайте папку `node_modules` и `dist`
4. Внизу страницы нажмите **Commit changes**

**Вариант Б: Через архив (рекомендуется)**

1. На вашем компьютере упакуйте проект в ZIP-архив (без `node_modules` и `dist`)
2. Разархивируйте архив в любую папку
3. На GitHub: **Add file** → **Upload files**
4. Перетащите все файлы и папки
5. Нажмите **Commit changes**

### Шаг 4. Создание тега версии

1. На странице репозитория справа найдите **Releases**
2. Нажмите **Create a new release**
3. Заполните:
   - **Tag**: `v1.0.0`
   - **Release title**: `Версия для хакатона`
   - **Description**: можно оставить пустым
4. Нажмите **Publish release**

## 💻 СПОСОБ 2: Загрузка через Git (командная строка)

### Предварительная установка

1. Установите Git: [git-scm.com/downloads](https://git-scm.com/downloads)
2. Проверьте установку:
   ```bash
   git --version
   ```

### Шаг 1. Настройка Git (один раз)

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш@email.com"
```

### Шаг 2. Создание репозитория на GitHub

1. Зайдите на [github.com/new](https://github.com/new)
2. Название: `alfa-credit-cabinet`
3. Выберите **Private**
4. **НЕ ставьте** галочки README, .gitignore, license (они уже есть в проекте)
5. Нажмите **Create repository**

### Шаг 3. Инициализация и загрузка проекта

Откройте терминал (Command Prompt / PowerShell / Terminal) и выполните:

```bash
# Перейдите в папку с проектом
cd путь/к/вашему/проекту

# Инициализируйте Git
git init

# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Initial commit: Умный кредитный кабинет"

# Переименуйте ветку в main
git branch -M main

# Привяжите удалённый репозиторий (замените YOUR_USERNAME на ваш логин)
git remote add origin https://github.com/YOUR_USERNAME/alfa-credit-cabinet.git

# Отправьте код на GitHub
git push -u origin main
```

### Шаг 4. Создание тега

```bash
# Создайте тег
git tag -a v1.0.0 -m "Версия для хакатона"

# Отправьте тег
git push origin v1.0.0
```

## 🖥️ СПОСОБ 3: Загрузка через GitHub Desktop

### Шаг 1. Установка GitHub Desktop

1. Скачайте с [desktop.github.com](https://desktop.github.com)
2. Установите и войдите в свой GitHub-аккаунт

### Шаг 2. Добавление проекта

1. В GitHub Desktop: **File** → **Add Local Repository**
2. Нажмите **Choose...** и выберите папку с проектом
3. Если Git не инициализирован, нажмите **create a repository**
4. Заполните:
   - **Name**: `alfa-credit-cabinet`
   - **Local Path**: уже заполнено
   - **Initialize with README**: ❌ снять галочку (уже есть)
5. Нажмите **Create Repository**

### Шаг 3. Публикация на GitHub

1. Слева увидите список изменённых файлов
2. Внизу введите описание коммита: `Initial commit`
3. Нажмите **Commit to main**
4. Нажмите **Publish repository**
5. Заполните:
   - **Name**: `alfa-credit-cabinet`
   - ❌ Снимите галочку **Keep this code private** (если хотите публичный)
6. Нажмите **Publish Repository**

## 🏃 ЛОКАЛЬНЫЙ ЗАПУСК БЕЗ DOCKER

### Предварительные требования

- **Node.js** версии 18 или выше: [nodejs.org](https://nodejs.org)
  - Скачайте LTS-версию
  - Установите
  - Проверьте: `node --version` (должно быть v18+)
- **npm** (устанавливается вместе с Node.js)

### Шаги запуска

```bash
# 1. Клонируйте репозиторий (или скачайте ZIP и распакуйте)
git clone https://github.com/YOUR_USERNAME/alfa-credit-cabinet.git
cd alfa-credit-cabinet

# 2. Установите зависимости
npm install

# 3. Запустите dev-сервер
npm run dev
```

### Результат

В терминале появится сообщение:
```
  VITE v6.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

Откройте в браузере: **http://localhost:5173**

### Сборка production-версии

```bash
# Сборка
npm run build

# Предпросмотр production-версии
npm run preview
```

Результат будет в папке `dist/` — это статические файлы, которые можно разместить на любом хостинге.

## 🐳 ЛОКАЛЬНЫЙ ЗАПУСК С DOCKER

### Предварительные требования

- **Docker Desktop**: [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)
  - Скачайте и установите
  - Запустите Docker Desktop
  - Дождитесь, когда появится зелёный индикатор "Engine running"

### Шаги запуска

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/alfa-credit-cabinet.git
cd alfa-credit-cabinet

# 2. Запустите через Docker Compose
docker-compose up --build
```

### Результат

Docker соберёт образ и запустит контейнер. В терминале увидите:
```
[+] Running 1/1
 ✔ Container alfa-credit-cabinet-app-1  Started
```

Откройте в браузере: **http://localhost:8080**

### Остановка

```bash
# В другом терминале
docker-compose down
```

3. Нажмите **Import**

### Шаг 3. Настройка деплоя

Vercel автоматически определит настройки:
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

Нажмите **Deploy**

### Шаг 4. Получение ссылки

Через 1-2 минуты получите ссылку вида:
```

```

Эту ссылку можно добавить в README как онлайн-демо.

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: `npm: command not found`

**Решение**: установите Node.js с [nodejs.org](https://nodejs.org)

### Проблема: `EACCES: permission denied`

**Решение** (Linux/Mac):
```bash
sudo chown -R $USER ~/.npm
```

### Проблема: `Port 5173 is already in use`

**Решение**:
```bash
npm run dev -- --port 3000
```
Откройте http://localhost:3000

### Проблема: Docker не запускается

**Решение**:
1. Убедитесь, что Docker Desktop запущен
2. Проверьте, что нет других приложений на порту 8080
3. Попробуйте: `docker-compose down && docker-compose up --build`

### Проблема: Белый экран в браузере

**Решение**:
1. Очистите кэш браузера (Ctrl+Shift+R)
2. Проверьте консоль браузера (F12) на ошибки
3. Перезапустите dev-сервер

### Проблема: Заявка не создаётся

**Решение**:
1. Убедитесь, что выбрали компанию
2. Заполните все обязательные поля
3. Проверьте консоль браузера на ошибки
