## Поток данных

### Клиентский путь

```
1. Выбор продукта
   └─> ProductCatalog → выбор → ApplicationForm

2. Заполнение заявки
   └─> Параметры (сумма, срок) → Цель → Подтверждение

3. Отправка заявки
   └─> CREATE_APPLICATION → SUBMIT_APPLICATION
   └─> Автоматический запуск конвейера

4. Отслеживание статуса
   └─> ApplicationTracker → отображение истории
```

### Банковский путь

```
1. Просмотр очереди
   └─> Pipeline/Queue → список заявок

2. Анализ заявки
   └─> DetailPanel → данные, скоринг, история

3. Принятие решения
   └─> RUN_SCORING → MAKE_DECISION
   └─> Обновление статуса
```

## Технологии

| Слой | Технология | Обоснование |
|------|------------|-------------|
| UI | React 18 | Популярность, экосистема, производительность |
| Типизация | TypeScript 5 | Безопасность типов, рефакторинг |
| Стили | Tailwind CSS 4 | Быстрая разработка, консистентность |
| Сборка | Vite 6 | Скорость, HMR, оптимизация |
| State | Context + Reducer | Простота, предсказуемость |
| Иконки | Lucide React | Лёгкость, кастомизация |

## Безопасность

- XSS-защита (React по умолчанию)
- CSP-заголовки (nginx.conf)
- Валидация входных данных
- Нет хранения чувствительных данных на клиенте

## Масштабирование

- Компонентная архитектура
- Модульность бизнес-логики
- Возможность замены state management на Redux/Zustand
- Готовность к интеграции с реальным API
- Docker-контейнеризация для горизонтального масштабирования
